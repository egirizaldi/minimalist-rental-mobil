# LuxeDrive Indonesia - Premium Car Rental Showcase

Website showcase untuk layanan penyewaan mobil mewah premium di Indonesia.

## Struktur File

```
├── index.html              # Halaman utama
├── katalog.html            # Katalog armada
├── paket_wisata.html       # Paket wisata & layanan VIP
├── tentang.html            # Tentang kami
├── contact.html            # Halaman kontak
├── assets/
│   ├── tailwind-config.js  # Konfigurasi Tailwind (shared)
│   ├── styles.css          # Custom CSS (shared)
│   ├── main.js             # JavaScript (shared)
│   └── images/             # Gambar lokal
└── README.md
```

## Fitur

- Responsive design (mobile & desktop)
- Hamburger menu untuk mobile
- Desain konsisten di semua halaman
- Gambar lokal (tidak依赖 external CDN)
- WhatsApp integration
- Smooth scroll & fade-in animations

## Cara Pakai

Buka `index.html` di browser, atau jalankan local server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
